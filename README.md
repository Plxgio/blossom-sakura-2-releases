# Blossom Sakura 2 · Descargas

[Descargar launcher para Windows](https://github.com/Plxgio/blossom-sakura-2-releases/releases/latest/download/BS2-Launcher-Windows.zip)

Extraé el ZIP completo y abrí **BS2-Launcher.exe**. El launcher instala el juego y el paquete de mods, y comprueba sus actualizaciones antes de jugar.

Si ya tenés BS2, elegí tu instancia existente y actualizá/repará. El acceso al servidor requiere la aprobación de whitelist y la contraseña de BS2.

Este repositorio distribuye versiones públicas. El código del proyecto, las cuentas, los mundos y las claves de publicación no se alojan aquí. El catálogo y el canal se firman antes de subirlos. Los componentes externos se descargan de sus fuentes oficiales y figuran en CREDITOS.json.

Los jugadores no necesitan una cuenta de GitHub para descargar.
